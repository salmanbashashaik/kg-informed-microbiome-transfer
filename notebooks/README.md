# Notebooks

This directory contains interactive exploration notebooks for inspecting the multi-relational knowledge graph, evaluating embeddings, and running zero-shot disease classification transfer.

---

## Available Notebooks

1. **`quickstart_tutorial.ipynb`**:
   - Walks through loading the 1,041-token genus vocabulary and 256-dimensional R-GCN embeddings.
   - Demonstrates building and inspecting the `MicrobiomeTransformer`.
   - Runs zero-shot inference and linear probing on example cohorts.
   - Visualizes attention weights across microbial genera.
